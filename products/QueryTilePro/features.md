This page covers all features included in Query Tile PRO for Azure DevOps, organized around the same four outcomes as the product overview. Features marked Free are available at no cost, no registration required. Features marked Paid require a subscription (free 30-day trial available).

## 📊 Build the tiles you actually need

**All query types & fields** Free
Build tiles from any Azure DevOps work item query, using any field — including custom fields and calculated expressions the standard tile can't touch.

**Field aggregations (Count, Sum, Min, Max, Average)** Free
Apply core aggregations across all fields and expressions, so a single tile can surface the number that actually matters instead of a raw list.

**Lead time & Cycle time aggregations** Free
Calculate lead time and cycle time based on field values, giving you delivery metrics without exporting data to a separate tool.

**Row-level calculations & field macros** Free
Apply calculated expressions and macros at the row level — percentages, derived fields, and other row-based logic — directly inside the tile.

**Multiple queries per tile** Paid
Combine more than one query and dataset inside a single tile, instead of being limited to what one query can return.

**Result-level & advanced calculations** Paid
Go beyond row-level math: run calculations and macros across combined query results to produce a single rolled-up number or metric.

**Charts** Paid
Turn query results into charts, so a tile can visualize a trend or distribution instead of just listing values.

**Plan & Progress view** Paid
Turn results into a Plan & Progress timeline, giving teams a visual read on delivery progress against a plan.

**Query Result widget (progress, rollups, styling)** *— tier TBD, see review notes below*
Decorate query results with progress indicators, rollups, and styling, layered on top of any query.

## 🚦 Highlight what matters

**Conditional formatting** Free
Flag good, warning, and critical states with color, so the numbers that need attention stand out without opening the tile.

**Styling through centralised stylesets** Paid
Manage styling and conditional formatting centrally through stylesets — define a style once, apply it in a click, and update it everywhere at once.

**Trend indicator (vs. fixed or data-sourced target)** Paid
Show an arrow or delta against a fixed or data-sourced target, so you can see at a glance whether you're ahead, behind, or on track.

**Business Hours calculation (business days, hours, holidays)** Paid
Calculate the difference between two dates in business hours, with support for defining business hours and importing holidays — so lead time and cycle time reflect your team's actual working schedule, not calendar time.

## ⚡ Make a performant dashboard

**Grouping (one tile, many teams/areas)** Paid
Define a tile once and have it render one instance per team, area, or category — instead of rebuilding the same tile by hand for every group, and instead of the dashboard loading a separate widget and query for each one.

## 🌐 Scale, consistency and governance

**Global Data Sources** Paid
Define work item queries once, centrally, and reuse them across dashboards and teams — so query logic stays consistent instead of being redefined project by project.

**Global shared stylesets** Paid
Apply a shared styleset across every tile that uses it, and change it in one place when styling needs to change.

**Global functions** Paid
Define a calculation once and reuse it across tiles, instead of re-entering the same logic on every dashboard.

**Global tile templates** Paid
Apply a saved tile configuration with a single click, making it faster to roll out a consistent tile setup across teams and dashboards.

**Change log for global settings** Paid
Track who updated a shared Data Source, styleset, function, or template, and when — so nothing drifts silently across hundreds of dashboards.
