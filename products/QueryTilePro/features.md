This page covers all features included in Query Tile PRO for Azure DevOps, organized around the same four outcomes as the product overview.
Features marked **Free** are available at no cost, no registration required. Features marked **Paid** require a subscription (free 30-day trial available).

<div class="wf-outcome" markdown="1">

## 📊 Build the tiles you actually need

<div class="wf-feature" markdown="1">

### All query types & fields <span class="wf-tier-badge wf-tier-free">Free</span>

Build tiles from any Azure DevOps work item query, using any field — including custom fields and calculated expressions the standard tile can't touch.

</div>

<div class="wf-feature" markdown="1">

### Field aggregations (Count, Sum, Min, Max, Average) <span class="wf-tier-badge wf-tier-free">Free</span>

Apply core aggregations across all fields and expressions, so a single tile can surface the number that actually matters instead of a raw list.

</div>

<div class="wf-feature" markdown="1">

### Lead time & Cycle time aggregations <span class="wf-tier-badge wf-tier-free">Free</span>

Calculate lead time and cycle time based on field values, giving you delivery metrics without exporting data to a separate tool.

</div>

<div class="wf-feature" markdown="1">

### Row-level calculations & field macros <span class="wf-tier-badge wf-tier-free">Free</span>

Apply calculated expressions and macros at the row level — percentages, derived fields, and other row-based logic — directly inside the tile.

</div>

<div class="wf-feature" markdown="1">

### Multiple queries per tile <span class="wf-tier-badge wf-tier-paid">Paid</span>

Combine more than one query and dataset inside a single tile, instead of being limited to what one query can return.

</div>

<div class="wf-feature" markdown="1">

### Result-level & advanced calculations <span class="wf-tier-badge wf-tier-paid">Paid</span>

Go beyond row-level math: run calculations and macros across combined query results to produce a single rolled-up number or metric.

</div>

<div class="wf-feature" markdown="1">

### Charts <span class="wf-tier-badge wf-tier-paid">Paid</span>

Turn query results into charts, so a tile can visualize a trend or distribution instead of just listing values.

</div>

<div class="wf-feature" markdown="1">

### Plan & Progress view <span class="wf-tier-badge wf-tier-paid">Paid</span>

Turn results into a Plan & Progress timeline, giving teams a visual read on delivery progress against a plan.
